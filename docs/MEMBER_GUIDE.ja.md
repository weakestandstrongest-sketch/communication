# Jam メンバー向けガイド

「Jam」は、サークル・部活の連絡（トーク・投票・予定と出欠・お知らせ・写真）をひとつにまとめたアプリです。App Store からのインストールは不要で、ブラウザで使えます。

---

## 1. はじめて使うとき

1. 管理者から届いた**招待リンク**をタップします。
   - LINE で受け取ったリンクは、自動的に Safari（Android は Chrome）で開きます。
   - LINE などのアプリ内ブラウザでは Google ログインができません。「ブラウザで開く」を選んでください。
2. **「Googleでログイン」**をタップし、自分の Google アカウントを選びます。
3. グループ名を確認して **「このグループに参加する」** をタップします。

招待コード（例: `AB3D5FGH7K`）を教えてもらった場合は、**グループ → 招待コードで参加** から入力します。

## 2. iPhone のホーム画面に追加する（おすすめ）

ホーム画面に追加すると、アプリのように全画面で使えます。通知を受け取るにはこの設定が必須です。

1. **Safari** でJamを開きます。
2. 画面下の **共有ボタン**（□に↑のマーク）をタップします。
3. **「ホーム画面に追加」** → **「追加」** をタップします。
4. 以後は、ホーム画面の **「Jam」アイコン** から開いてください。

> iOS 16.4 以降が必要です。Android の Chrome では、メニューの「ホーム画面に追加」または「アプリをインストール」から追加できます。

## 3. 通知をオンにする

1. ホーム画面のアイコンからJamを開きます（iPhone の場合）。
2. **設定 → 端末への通知 → 「この端末で通知を受け取る」** をタップします。
3. 「通知を許可しますか？」と表示されたら **「許可」** を選びます。
4. **「テスト通知」** をタップして、通知が届くか確認しましょう。

通知が届くもの:

- 新しいメッセージ（自分が見ているトークは除く）
- メンション・返信
- 新しい投票、締切が近い未回答の投票
- 新しい予定、出欠確認、予定の変更・中止、もうすぐ始まる予定
- お知らせ

**通知を減らしたいとき**

- トークごと: トーク画面右上の ⓘ →「通知オフ」
- グループごと: グループ → ⚙ → 「このグループのプッシュ通知」
- メッセージの内容を通知に表示したくない場合: 設定 →「通知にメッセージ内容を表示」をオフ

## 4. プロフィール写真とグループのアイコン

- **プロフィール写真**：設定 →「プロフィール写真を変更」で、好きな写真に変えられます（正方形に切り抜かれます）。変更しない場合は Google アカウントの画像が使われます。「写真を削除」で頭文字のアイコンに戻せます。
- **グループのアイコン**：管理者は、グループ → ⚙ →「アイコンを変更」で設定できます。

## 5. パート・バンド

グループの中に、パートやバンドごとの小さなグループを作れます。グループ →「パート・バンド」の **＋作成** から、名前とメンバーを選んで作成します。

- **専用のトーク**ができます。メンバー以外には見えません。
- パート・バンドの画面の **「予定を追加」** で作った予定は、**そのメンバーだけに表示・通知**されます（グループのほかの人や管理者には見えません）。予定画面の上のタブで、パート・バンドごとに絞り込めます。
- メンバーの追加はメンバーと管理者が、メンバーを外す・削除は作成者と管理者ができます。自分はいつでも退出できます。

## 6. 意見箱（匿名）

グループ → **「意見箱」** から使えます。「この曲のここがよくない」「練習のここを変えたい」といった、言いにくい意見を匿名で言い合うための場所です。

- 投稿者は、**ほかのメンバーにも管理者にも表示されません。**
- 曲名などの**お題**を付けると、同じお題の意見をまとめて見られます。
- 投稿をタップするとスレッドが開き、匿名で返信できます。返信した人は「匿名A」「匿名B」のように区別され、投稿した本人は「スレ主」と表示されます。
- ハートでいいねできます。自分の投稿・返信は、メニューから削除できます。
- 人を傷つける内容は、管理者が削除することがあります。
- 注意：メンバーが少ないグループでは、内容や時間帯から書いた人を推測できてしまうことがあります。

## 7. 基本の使い方

| 画面 | できること |
| --- | --- |
| **ホーム** | 「対応が必要」に、未回答の投票・出欠確認・重要なお知らせがまとまって表示されます。ここを見れば、やることがわかります |
| **トーク** | グループトーク・個別トーク。長押し（パソコンは右クリック）でリアクション・返信・コピー・編集・削除。＋ボタンから写真・ファイル・投票・予定・お知らせを送れます |
| **予定** | 「カレンダー」と「タイムライン」を切り替えられます。カレンダーは二本指でつまむ・広げると、ドット表示 → 予定名 → 詳細と拡大できます。左右にスワイプで月を移動（選んでいた日の丸が、次の月の同じ日へ移ります）。上の「10月 2026年」をタップすると、年と月をくるくる回して選び、その月へ移動できます。タイムラインは1日の流れ（空き時間も表示）。予定をタップして **参加 / 未定 / 不参加** を回答。「カレンダーに追加」で iPhone のカレンダーにも登録できます。画面右下の **＋ボタン**から予定を追加できます |
| **投票** | 「未回答」タブで回答していない投票を確認。締切間近・終了した投票もここで確認できます |
| **グループ** | お知らせ・メンバー一覧・アルバム・招待・グループ設定 |

**ヒント**

- メッセージを左にスワイプ（またはダブルタップ、パソコンはダブルクリック）すると、すぐに返信できます。
- 「@」を入力すると、メンバーをメンションできます。
- トークの削除：トーク一覧でトークを長押し →「トークを削除」（トーク画面の ⓘ からも）。**自分の一覧と履歴だけ**が消え、相手には影響しません。相手からまたメッセージが届くと、新しいメッセージから表示されます。グループのトークは、履歴だけが消えてトーク自体は残ります。
- トーク画面右上の 🔍 で、そのトークのメッセージを検索できます。結果をタップすると、そのメッセージへ移動します。
- メッセージを長押し →「トーク上部に固定」で、大事なメッセージをトークの一番上に固定できます（全員に表示。× で解除）。
- 自分のメッセージを長押し →「既読メンバー」で、誰が読んだか確認できます。
- 電波が悪くて送信できなかったメッセージは赤く表示されます。「再送信」をタップしてください。

## 8. よくある質問

**Q. 匿名投票は本当に匿名ですか？**
A. 誰がどれに投票したかは、管理者を含むほかのメンバーには表示されません。

**Q. 機種変更・別の端末で使いたい**
A. 同じ Google アカウントでログインすれば、トークや予定はそのまま見られます。通知は端末ごとにオンにしてください。

**Q. 共用の端末でログアウトしたい**
A. 設定 → ログアウト。その端末への通知も止まります。

**Q. グループを退会したい**
A. グループ → ⚙ →「グループを退会」。オーナーは先にほかのメンバーへオーナーを譲渡してください。
